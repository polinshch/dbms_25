# dbms_25

Проект сделан по предмету "Основы баз данных". 

В процессе было 3 этапа:
- сбор данных
- организация хранения данных
- реализация веб-интерфейса

--------------------------------------------------
**Интерфейс веб-приложения включает следующие вкладки:**
1. Поиск статей по автору - функция для поиска научных публикаций определенного автора с возможностью фильтрации по предметным областям.
2. Поиск соавторов - функция для выявления всех соавторов указанного исследователя с информацией о совместных публикациях.
3. Поиск авторов по ключевым словам - функция для поиска авторов, чьи публикации связаны с указанными ключевыми словами.
